## ✦ 这是个啥？

简单来说，这是我自己一个人慢慢做出来的一个网页美化小工具。
没有什么高大上的技术，主打一个**好看、好玩、顺手**。
整个东西就装在一个文件里，点开 `index.html` 就能直接玩，不用安装，不用搞那些复杂的配置。

## ✦ 里面都有啥？（点开就能看到）

里面藏了不少我自己想出来的小玩意儿，大概长这样：

*   **🎭 表情包系统**：自带一堆表情，而且你聊天的时候，AI 还会看你的语境，自动帮你把最合适的表情包甩出去。
*   **🤖 AI 陪聊**：我给它捏了几个角色卡，还能跟里面的小宠物聊天，养久了有感情。
*   **🎴 捉宠养成**：可以抽卡、看宠物图鉴、养大它们，甚至还能把它们放在桌面上当桌宠。
*   **🔊 语音包**：有系统自带的音效，还预留了好几个云端语音接口，以后说不定能让它开口说话。
*   **🎨 好看的外壳**：那种软乎乎的拟态 UI（看着像捏一下会弹回来），加上毛玻璃弹窗，视觉上很舒服。
*   **🌓 白天黑夜**：一键就能切换明暗模式，晚上看也不刺眼，所有颜色都会自动跟着变。

## ✦ 咋用啊？

特别简单，找到 `index.html`，双击打开，就完事了。
不需要你懂什么技术，你只要打开浏览器就能用。
