02参数怎么调:数值变大变小的实际效果›

参数就是能拧的旋钮,拧完立即看到。挑常调的几组:

宽 / 高 · 大小

宽装内容的盒子横向尺寸高纵向尺寸

数值变大 = 更宽松,变小 = 更紧凑。太宽会顶到边;太窄会挤断文字。

X / Y · 位置偏移

X右移正、左移负Y下移正、上移负

用于阴影方向、装饰错位。常规拟态阴影 Y:2~6px 就够。

四角圆角

0~4硬朗直角8~14常规圆角≥ 一半宽高胶囊/圆

边框粗细 / 位置 / 颜色

1~2px精致3~4px硬朗>4px笨重不推荐

阴影 · 模糊 / 扩展 / 透明度

模糊越大越"浮"扩展整块摊大透明度>0.12 就脏

轻拟态推荐 0 2px 8px rgba(0,0,0,.06)。

字体 · 字号 / 字距 / 行高

正文12~14标题16+字距0.01~0.03em 韩系行高1.5~1.75

Tip:所有数字都可点击输入精确值。

功能介绍

· 中转站管理：支持多套中转站预设保存，可自由切换不同 API 配置，省去反复填写的麻烦

· AI 对话助手：内置智能助手，可帮你快速定位功能、调节参数、操作按钮，一键搞定

· 屏幕控制演示：操作时屏幕会出现鼠标指针动效，清晰展示每一步在做什么

· 自定义功能：支持滑块、输入框等参数调节，满足各种使用场景

· 聊天气泡：可自定义消息气泡样式（圆角、背景色、文字色等），打造个性化对话界面

· 聊天主页：管理你的对话列表，支持新建、重命名、删除、搜索对话记录

· 开始制作：一键进入制作模式，快速搭建你的中转站配置

· 设置中心：集中管理所有参数（中转站、主题、AI 角色等），方便统一调配

· 中转站预设：保存多套中转站配置（名称+Base URL+API Key+模型名），一键切换

· 消息记录：本地保存所有对话历史，随时回看

· 数据备份：支持导出/导入配置，防止数据丢失
