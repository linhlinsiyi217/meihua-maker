# 美化小叽 · 项目约定（v0.9.1+）

## 版本与更新日志规则（强制）
**每次返修 / 更新 / 新增功能 / 修复 bug 后，必须自动执行以下操作，无需询问用户：**
1. 升 `APP_VERSION`（按语义版本：修复 bug 升 patch 如 0.9.1→0.9.2，新功能升 minor 如 0.9→0.10，大改升 major）
2. CHANGELOG 顶部新增对应版本条目（含日期 + 改动项，标签用 add/chg/fix）
3. 同步所有版本显示位：顶栏 `brandVer`、首页 chip、更新日志徽标 `clBadge`
4. GetDiagnostics 验证 0 错误

## UI 风格基准（v0.9.1 确立）
- **核心风格**：Neumorphism 拟态，不是纯玻璃
- **玻璃仅限**：弹窗 / 启动画面 / 语音条 / 表情半窗
- **拟态参数**：阴影 6px/12px，圆角 26px（卡片）/ 16px（按钮），曲线 `cubic-bezier(0.34,1.56,0.64,1)`
- **文字色**：全部走 `--text-primary` / `--text-secondary` / `--text-disabled`，禁止硬编码
- **表面色**：`--surface` / `--surface-2` / `--surface-3`
- **反色白字**：`--ink-inv`（深色按钮/气泡上）
- **图标**：纯 SVG 线条，不用 emoji；Dock 4 按钮（主页/功能/设置/小淮宝），小淮宝用机器人头图标
